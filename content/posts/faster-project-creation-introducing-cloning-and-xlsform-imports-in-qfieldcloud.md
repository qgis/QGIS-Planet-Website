<p>We’ve overhauled the project creation flow in <a href="https://qfield.cloud/" rel="noopener" target="_blank">QFieldCloud</a>
 to make getting your field data campaigns off the ground faster than ever. Along with a clean new web interface, we are introducing two highly requested features to boost your team’s productivity: more advanced project creation, with native XLSForm imports and 1-click project cloning! 🚀</p>
<h2 id="revamped-basic-project-creation">Revamped basic project creation</h2>
<p>When creating a new project, you can now define the initial extent field right away. You can also configure a basemap using OSM or a custom XYZ layer. What is more, you can set whether you prefer to keep the original color, or convert the basemap into dark or light themes.</p>
<h2 id="xlsform-imports-a-new-path-of-survey-creation">XLSForm imports: a new path of survey creation</h2>
<p>We are also thrilled to introduce a completely new way to generate projects: XLSForm support.</p>
<p>If your team designs surveys using the industry standard XLSForm spreadsheet format, you no longer have to manually recreate those schemas as QGIS layers. You can now bootstrap a fully functional geospatial project directly from your spreadsheet.</p>
<p>Simply select the XLSForm option during project creation, upload your <code>.xls</code> file into the designated field, and QFieldCloud will translate your survey logic, constraints, and questions into a ready to use field project.</p>

<h2 id="project-cloning-replicate-your-field-setup-in-seconds">Project cloning: replicate your field setup in seconds</h2>
<p>Setting up a new data collection project that shares the same structure as an existing one used to be a manual chore. If a team wanted to replicate a workflow for a different region or phase, they had to create a new project from scratch, configure it in QGIS, and re-upload all the base maps, datasets, and project files.</p>
<p>That changes today. With our new cloning feature, you can duplicate an entire project environment with just a couple of clicks:</p>
<ol>
<li>Click the <strong>Create Project</strong> button.</li>
<li>From the three new options, select <strong>Clone an existing project</strong>.</li>
<li>Use the search input to find and select the target project.</li>
</ol>
<figure class="figure text-center mb-4"><img alt="Cloning an existing project in QFieldCloud" class="figure-img img-fluid gallery-img" height="933" src="/img/subscribers/qfield/faster-project-creation-introducing-cloning-and-xlsform-imports-in-qfieldcloud/qfieldcloud-project-cloning_hu_ad3e14ab841a5d18.webp" width="850"/></figure>
<p>That’s it! QFieldCloud will generate a 1:1 clone of the original project. All your underlying QGIS project files (<code>.qgs</code>/<code>.qgz</code>), layers and styling are instantly carried over to the new project. This eliminates repetitive desktop-to-cloud syncing and ensures standard data collection practices across your entire organization.</p>

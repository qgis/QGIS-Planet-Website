<p><img alt="" class="aligncenter size-full wp-image-10606" height="533" src="/img/subscribers/qgis_oslandia/qgis-user-conference-2026-laax/conf-qgis-laax.webp" width="1198"/><img alt="🌎" class="wp-smiley" src="/img/subscribers/qgis_oslandia/qgis-user-conference-2026-laax/1f30e.webp" style="height: 1em;"/> The QGIS User Conference is an annual event that brings together users and developers of the QGIS open-source geographic information system (GIS). The conference offers an opportunity to discover the latest developments in QGIS, share real-world experiences, and network with the global QGIS community across administrations, industry, academia, and beyond.</p>
<p>The event is organized by OPENGIS.ch, the Swiss QGIS user group with support from the QGIS project.</p>
